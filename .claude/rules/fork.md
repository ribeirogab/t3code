# Fork changes

This repository is a personal fork of pingdotgg/t3code. Read `fork/README.md` before you change it.

- Every change goes through a pull request into `custom`, as `fork/README.md` describes. Never commit or push to `custom` directly.
- After you open the pull request, stop and ask the owner to approve it. Merge only after the approval. The merge publishes a release.
- Put new code in new files under `fork/` or `apps/web/src/fork/`. Change upstream files as little as possible.
- Do not add database migrations.
- The repository is public. Keep private data out of every file, commit, and pull request: hostnames, addresses, IPs, personal paths, and emails.
